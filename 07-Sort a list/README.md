# Sort a list by the last digit of each item, from highest to lowest

## Question/problem
Below is a list of strings called **nums**. Write a function called **last_char** that takes a string as input, and returns only its last character. Use this function to sort the list **nums** by the last digit of each number, from highest to lowest, and save this as a new list called **nums_sorted**.
nums = ['1450', '33', '871', '19', '14378', '32', '1005', '44', '8907', '16']

## Expected output
A new sorted list

## How to run
python3 main.py
