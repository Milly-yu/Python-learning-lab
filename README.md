# S&P 500 and Interest Rate Analysis

### Problem/question: 
Read monthly data for 2016 and 2017 and compute the average S&P 500 closing prices('mean_SP') as well as the highest long-term interest rate('max_interest') for the period from June 2016 through May 2017.

### Expected Output:
'mean_SP': average S&P 500 closing price for the period.
'max_interest': maximum long-term interest rate for the period.

# How to run:
Bash
python3 SP500.py
